Reports fields that are never read or written outside their own declaration. Fields carrying compile-time metadata are exempt - metadata exists to be consumed by macros, so such fields may be used invisibly.

Example:


class Session {
    var started:Bool = false;   // nothing reads or writes it
    public function new() {}
}

When compiler diagnostics report usages (for example from macro-generated code), those count as uses. Use @:keep to exempt a field deliberately.
