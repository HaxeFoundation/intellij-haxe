Reports variable, field, method and other symbol names that cannot be resolved with the imports and packaging rules in effect.

Example:


class Greeter {
    public function greet():String {
        return salutation;   // no such field or variable
    }
}

Quick fixes can create the missing local variable, field, method, parameter or enum value. When compiler diagnostics are enabled, names the compiler accepts (for example macro-generated fields) are not reported.
