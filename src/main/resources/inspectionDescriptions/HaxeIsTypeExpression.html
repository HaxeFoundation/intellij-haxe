Reports invalid is operator usage: the right-hand side must be a plain type - not an expression, a type with parameters, or a non-core abstract.

Example:


var items:Array<Int> = [];
if (items is Array<Int>) {}   // type parameters are not allowed here

Below language level 4.2 the stricter pre-4.2 rules apply automatically: an unparenthesized is expression is only allowed in a plain if condition. The 4.1 compatibility option keeps those rules on at newer levels for code that must still compile on Haxe 4.1.
