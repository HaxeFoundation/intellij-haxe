Reports initializers whose type does not fit the declared type - on local variables and fields - plus Void used as a value and null-coalescing (??) operands whose types cannot unify.

Example:


var age:Int = "old";           // String is not assignable to Int
var name:String = count ?? "n/a";   // Int and String do not unify
Quick fixes can change the declared type, remove the initializer, or wrap the value in a standard conversion such as Std.string(...).
