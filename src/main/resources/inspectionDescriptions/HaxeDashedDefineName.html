Reports a define name containing a dash in a build file: -D my-flag in an hxml file, or <haxedef name="my-flag"/> and <define name="my-flag"/> in a Lime, OpenFL or NME project file.

For conditional compilation the compiler maps every dash to an underscore, so -D my-flag is tested as #if my_flag. #if my-flag tests only my, and #if (my-flag) does not compile. Macros accept either spelling.

Example:

-D my-flag
-D log-level=2

After the quick-fix is applied:

-D my_flag
-D log_level=2
