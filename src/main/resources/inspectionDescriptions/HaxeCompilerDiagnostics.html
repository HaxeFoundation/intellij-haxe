Reports errors and warnings exactly as the Haxe compilation server's display/diagnostics reports them: compiler and parser errors, deprecation warnings, unresolved identifiers and missing interface fields.

Because the real compiler runs the build's macros, this also covers code the static analysis cannot see, such as macro-generated fields.

Active only while Use compiler diagnostics and its Errors and warnings toggle are enabled on the Haxe Compiler settings page, and the project uses the compilation server. Deprecation warnings whose replacement does not exist at the module's language level are filtered out.
