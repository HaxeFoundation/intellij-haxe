Reports override problems: a modifier on a method that overrides nothing, a missing modifier where one is required, overriding static, inline or final methods, and overrides that reduce visibility. Classes built by macros downgrade the missing-override case to a weak warning, since the parent method may be generated.

Example:


class Animal {
    public function speak():Void {}
}
class Dog extends Animal {
    public function speak():Void {}   // must be declared `override`
}
