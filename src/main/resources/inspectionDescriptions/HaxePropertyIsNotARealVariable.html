Reports storage-less properties used as if they had a backing field: an initializer on a property without physical storage, or the property's own accessors reading/writing it directly (which would recurse).

Example:


class Counter {
    public var value(get, never):Int = 1;   // no storage to initialize
    function get_value():Int {
        return value;                        // reads through the getter again
    }
}
Quick fixes add @:isVar to give the property real storage, or remove the initializer.
