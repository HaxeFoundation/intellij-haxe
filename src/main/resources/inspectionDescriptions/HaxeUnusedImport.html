Reports import statements that provide types not used in the current file, including duplicates of an earlier import. The quick fix removes the statement; an "optimize imports" style fix removes all unused imports in the file at once.

Example:


import haxe.ds.StringMap;   // nothing below uses StringMap

class Launcher {
    static function main() trace("started");
}

When the compiler-diagnostics unused-import feature is enabled, this static inspection stands down in favor of the compiler's post-macro view.
