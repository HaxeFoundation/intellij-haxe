Reports assignments where the value's type does not match the type of the variable being assigned to, including rebinding of non-dynamic methods and writes to final variables.

Example:


var count:Int = 0;
count = "many";        // String is not assignable to Int

final limit = 10;
limit = 20;            // cannot assign to a final variable
Conversion quick fixes wrap the value where a standard conversion exists, e.g. Std.parseInt("42") or Std.string(value).
