Reports code spans the Haxe compiler proves removable, such as unused pattern variables, with a quick fix that deletes the span (or applies the compiler's suggested replacement when it provides one).

Example:


switch (value) {
    case Some(inner): trace("got one");   // `inner` is never used
    case None:
}

Active only while Use compiler diagnostics and its unused-code toggle are enabled on the Haxe Compiler settings page; while on, it replaces the plugin's static unused-code inspections.
